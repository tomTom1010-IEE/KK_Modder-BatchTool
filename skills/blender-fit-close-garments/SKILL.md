# 贴身衣物适配素体

## 共用流程

开始前读取并执行 [衣物迁移素体通用技能](../blender-transfer-garments/SKILL.md) 的场景读取、备份、坐标与资产处理、设计特征保留和验收要求。以下仅补充贴身衣物特有的决策；“无穿模”不等于贴身完成。

## 迁移前先识别原有分区松紧

**贴身衣物并不代表每个区域都同样贴身。先读出源衣物的有效设计信息，再制定贴合目标。**

- 在源衣物与源素体的对应姿态下，识别紧贴区、适度留量区、刻意架空或跨越凹陷的区域、厚度/装饰及可见开口边缘。结合正侧背视图、截面、边界与面内采样判断，不能只用全衣平均距离或顶点最近距离分类。
- 记录各区的相对松紧、轮廓、间隙分布及过渡位置；间隙须区分贴身侧与外表面，扣除厚度影响，避免将外侧凸饰误判为衣服太松。原服装的局部宽松、撑起及跨接形态也属于需要迁移的特征。
- 结合源造型、拓扑和依附关系区分有意留空、已有破损、错误姿态/权重和异常素体；不要照搬源错误，也不要把所有正间隙当成缺陷。源参考不全时标明不确定区域，优先保留其造型。
- 将分区随解剖对应和衣料特征一起迁移：紧贴区及应贴合的边界主动收紧；原有留量区保持相对松量与设计轮廓；区域间连续过渡。不机械复制世界坐标毫米数，也不统一压到目标素体上。
- 用户明确要求改变某处松紧时，以该要求更新该区目标；不要将局部收紧扩散到其他设计留空区。后续贴合与验收均以这份分区基线为依据。

## 先解决对应关系，再追求小间隙

先检查身体与衣服是否存在相同的解剖区域对应：肩、胸、腰、髋、裆底、腿根、膝、踝、脚背和足底。

- 判断衣服和素体的静止姿态、当前姿态、腿部张角、躯干长度与裆高是否不同。
- 单独检查躯干与双腿交界线。裆高不一致时，最近表面往往是左右大腿内侧，不能直接当作正确的贴合目标。
- 比较腿口端点、前后裆线和侧胯转折，而不只比较一个最低点。必要时先抬升、旋转或重排裁片的过渡方向，再进行表面贴合。
- 明确左右、前后及内外层对应，防止顶点越过中线、跨腿投射或前后表面互换。
- 数值较小的表面距离也可能是错误对应：衣服挤在大腿内侧时，距离很近，但裁片已经变形。

## 素体异常与分区贴合优先级

- 素体不是处处可信的目标。先识别骨骼错位、权重或非原生运行环境造成的局部异常突起；不要将这些异常复制到衣服上。本次用户指出胸口异常与 `spine 20` 在非原生环境中的影响有关，这是该资产的线索，不是通用骨骼规则。
- 对被不透明衣料完整遮盖的异常区域，优先采用原服装的平顺形态和设计轮廓，允许适量余量。不刻意刻画乳头等非设计细节，不以每点紧贴身体作为成功条件。
- 用原衣服和异常区周围可信区域建立平滑过渡或局部包络。对异常区关闭或降低逐点吸附目标；接触检查仍需保留，但不能为了追逐异常突起而再次制造尖点。可将衣服整体局部平顺外移以保持遮盖。
- 对源设计或用户要求应贴合的袖口、领口、裤脚等可见开口边缘，单独设置边界约束并尽量收紧；遮盖区的宽松容差不得扩散到这些边缘。保留设计上本就存在的开口、翻起、松量和厚度。
- 不擅自修改素体骨骼、权重或删除身体网格。若平顺服装无法遮住异常素体，明确说明残余穿出及所需的素体修复，不能将穿模当作已遮盖。

## 选择变形策略

按问题选择组合，避免把所有问题都交给同一项距离最小化：

| 问题 | 优先处理方式 |
|---|---|
| 整体体型或姿态不匹配 | 粗尺度对齐、区域对应与平滑空间变形 |
| 裆线过低、腿口角度不一致 | 从干净源网格恢复该区，先调整解剖对应与裁片走向 |
| 本应紧贴的区域已无穿模但仍宽松 | 对照源分区主动收紧，测量正间隙；保留原有留量区，装饰作为附属件跟随 |
| 局部穿模 | 带邻域约束的接触修正，避免单点尖刺 |
| 顶点挤团、折叠或左右交叉 | 回到对应的干净源区域重新求解，而非继续在坏网格上推点 |
| 设计直线变弯 | 建立明确的直线或投影约束，平滑传递到邻近网格 |
| 腰部新增褶皱 | 检查变形过渡、采样及厚度层；必要时构造平顺截面包络 |

数值实现与这些方法的陷阱见 [references/methods-and-failures.md](references/methods-and-failures.md)。编写求解器或遇到反复失败时读取它。

### 收紧与接触

- 区分“移出素体”和“向内收紧”：只有向外推的算法会留下原有的大空隙。
- 按区域统计主体衣料的有符号间隙，饰条、厚底和边饰另算。报告中位数、高分位数、最坏位置，不能用全身均值掩盖脚底或裆部。
- 间隙目标先依据源模型的分区松紧，再结合目标尺度、衣料厚度、用途和低模曲率选择。毫米级可作为人体尺度紧贴区的试验起点，不能套用为全衣或所有资产的固定要求。
- 同时采样顶点、边和面内部；细分检查易漏检区域。每轮重要修改后检查真实三角面相交。
- 内收、平滑或拉直后重新检查接触，因为每一项都可能重新引入穿模。

### 裆部局部恢复

按通用技能固定已认可区域并恢复源对应；先修正裆高、左右和前后对应，再贴合。修复区与固定区连续过渡，避免新的腰部折痕。

### 修复新增腰部褶皱

先按通用技能识别并保护原有褶皱布线及直锐边，只修复迁移新产生的波纹。必要时拟合连续身体截面，生成略在素体外侧的平顺包络；重建后按源模型恢复有意制作的脊谷、支撑面和收尖。不能把所有层置于同一半径，也不能把原有褶皱当作拟合噪声抹平。

## 有依赖关系的衣物与依附饰件

适用于扣件、饰带、护片等依附于另一件衣物的资产。此类对象的直接贴合目标通常是已适配的承载衣物，不能仅按素体最近点独立迁移。

- 先记录并迁移衣物间的依赖、附着位置、比例、朝向、特征对应、间隙及叠放关系，再在保持这些关系的前提下局部贴合。
- 同时保护饰件内部的凸凹方向、倒角、厚度、直边和连接结构；衣物间贴合不能覆盖衣物内部的造型约束。剖面已损坏时从有效备份恢复。
- 对确属依附式的饰件采用**可见边缘贴合优先**：内部造型整体随动，遮挡背面不必逐点紧贴；仅在实际被遮挡且不会显露的区域容许微小穿入。可见正面、轮廓、镂空和饰件自交仍须独立验收。
- 继续遵守本技能的源松紧分区、解剖对应、异常素体处理和通用法线规范。边缘优先不等于自动细分，下面的收口加密仍是有条件的可选项。

遇到这类对象时读取 [依赖衣物与饰件的适配方法](references/dependent-garments.md)，其中定义双重特征约束、遮挡容差及验收方式。

## 可选：收口边缘加密与专项贴合

**仅在用户明确要求优化收口，或用户反馈收口缝隙、边缘不贴合等相关问题时执行。** 普通贴身迁移不自动启用此步骤，不因发现衣物有袖口、袜口就自行细分。用户要求保留拓扑时遵守该限制。

- 适用于袖口、长筒袜口、脚部开口等边界。先备份，识别真实开口、厚度侧面和相邻布料，通常只处理边缘一圈或两圈面及必要过渡；不要封住设计开口。
- 对布料面作局部细分，增加沿边缘轮廓的采样。厚度侧面只沿收口环向分段，连接内外层、跨越厚度的边不切分。这里的方向以局部布面和厚度剖面为准，不能机械使用世界 XY 轴。
- 多圈窄布边、翻边、硬边设计作为完整剖面保留。环向对应位置的各层共同移动，不将内外层分别吸到身体上；保护原有厚度、剖面起伏、锐边标记与外侧设计线。
- 专门对贴身侧边缘顶点建立接触目标，保留小而合理的间隙。不要误把外侧装饰凸缘作为贴身侧。将修正连续传递到邻接布面，固定其余已认可区域。
- 加密程度和间隙按模型尺度与曲率选择；本次三段环向细分及约 0.65 mm 间隙只是已试验参数，不是通用常数。局部拓扑改变后更新源对应，保留和核对 UV、材质、颜色及所需权重。
- 验收检查厚度方向原边未被切断、剖面形状仍在、边缘贴合、实际面穿插与局部自交，以及线框和实体外观。按通用技能检查修改后的自定义法线，避免细分后的假褶皱漏检；不能仅用重新创建的裸网格预览作为最终验收。

## 贴身验收补充

执行通用技能的中央布线稳定检查，尤其关注裆下、前后中心接缝及窄饰带。对称中线偏移、折返或两侧宽度突变时，先检查局部挤压与内部剖面，不能用整体平均间隙、零身体相交或“固定区域未改动”代替这一检查；中线正常也不免除其他几何检查。

执行通用技能的完整验收，按迁移前记录的分区分别检查应紧贴区域的过大间隙、留量区是否被误压平，以及裤腿、脚背、足底、裆底的错误对应；异常素体遮盖区采用已说明的余量。直锐边与原有褶皱必须在收紧后仍然保留。

依附饰件额外核对衣物间特征对应、内部剖面及可见边缘；将被遮挡的允许穿入与可见穿模、自交分别报告。仅零身体相交、平均距离变小或自交配对数量不变，都不能证明贴合与设计完整。
