# 数值方法与本次试错记录

这些方法是可选工具，不是一套可直接套用到任意模型的固定参数。此次模型的手工顶点编号、人体坐标、环境路径与脚本参数不可复用为通用算法。

通用坐标回写与相交检测规则见 [通用几何流程](../../blender-transfer-garments/references/geometry-workflow.md)，编写求解器时读取。

## 约束求解的构成

可以组合接触、间隙目标、局部形状保持、厚度层耦合、装饰附着和固定区约束。用相邻原始边向量或局部旋转保持细节，例如局部/整体 ARAP；不要把它当作保证无折叠的证明。

空间邻近边有助于让内外层一起移动，但需排除跨腿、无关邻接和不应粘合的开口。稀疏求解器的固定区最好通过消元固定自由度，而不是只给它很大的惩罚权重。

饰条可通过基底三角形重心坐标跟随衣料，并保存其法向/切向偏移。大旋转时，应旋转偏移向量；直接保留世界坐标偏移不能保持真实附着关系。

## 防止错误表面对应

最近点查询不理解身体语义：

- 裆底可能被分配到大腿内侧。
- 两腿接近时可能跨腿。
- 有开口、双面或法线不一致的素体会使有符号距离误判。

必要时限制候选身体区域、采用方向射线、骨骼/解剖分区或显式对应点。检查法线方向和表面是否适合距离符号判定。符号距离为正并不能证明无三角面穿插。

## 折叠恢复与平滑变形场

局部/整体保形优化可以改善边长，却仍可能在狭窄裆部压缩边、交换左右或折叠薄层。此次仅增加刚性权重不能修复错误对应。

有效的修复顺序是：

1. 使用未损坏网格恢复区域顶点的相对排列。
2. 显式调整裆高与裁片的躯干—腿部过渡。
3. 在源网格空间构造连续位移场，使空间上接近的层与装饰共同移动。
4. 执行平滑接触修正，并验证中线两侧、局部面质量和自交。

高斯位移平滑不是必然可逆的变形；平滑场仍可能造成局部折叠。若以微分同胚、正雅可比或“保体积”为名，需要实际实现和验证相应性质，不能仅因使用平滑邻域就这样描述。

## 腰部截面重建的条件

适用于主要是连续躯干壳层、对应已正确但出现非设计褶皱的区域。先保护源模型中有意制作的褶皱脊谷、窄面带及收尖，重建包络不能替代这些设计。

- 先确认截面中心在躯干内部，射线不会误击手臂或其他层。检测未命中、多次命中和不连续跳变。
- 对随高度与角度变化的半径场作平顺拟合，保留真实腰臀轮廓，不强行变成圆柱。
- 可生成平滑外包络以缓解身体低模面片造成的小凹凸。包络偏移仍需经实际面相交检查。
- 上下过渡使用连续权重，并检查导数与轮廓，避免在平滑区边缘形成环状折痕。
- 保留内外层相对偏移、包边与硬边。径向统一贴面会压塌厚度。
- 从原始网格恢复残余细节时，不能无条件加回所有拟合残差：大残差可能是模型曲率、对应错误或拟合误差，而不是应该保留的细节。按结构识别、限制异常值并目视核对。

## 本次失败 → 可复用教训

| 失败 | 原因 | 后续决策 |
|---|---|---|
| 已无穿模，裤腿与足底仍松 | 求解只向外推，没有主动收紧 | 同时衡量负间隙与过大正间隙，按部位验收 |
| 裆部紧贴却严重挤团 | 原衣服裆高与素体不一致，最近点落在腿内侧 | 先修正解剖对应，再贴合 |
| 增加保形权重仍有折叠 | 局部能量没有纠正错误的目标区域 | 从干净源区域恢复，用平滑整体变形和明确对应 |
| 用户认可部位被下一轮扰动 | 每轮继续全身优化 | 建立固定区和局部过渡带，比较固定区位移 |
| V 形设计线变弯 | 自由平滑未包含设计约束 | 约束指定边链，并在后续步骤持续维护 |
| 腰部出现新褶皱 | 位移过渡不连续、最近表面噪声及不恰当残差 | 检查截面连续性，构造平顺包络并筛选真实细节 |
| 平滑腰部后自交增加 | 同一半径贴面压塌内外层 | 分辨层次，恢复相对厚度，不只追求平滑外观 |
| 每次“修完”仍被截图发现问题 | 过早把零身体相交当成完成 | 同时检查裁片、线框、厚度、间隙与局部近景 |

本次没有充分验证动画姿态、真实厚度误差、所有装饰层间自交、UV 拉伸和重绑后的效果。技能使用时不能将这些未验证内容描述为已经由试验保证。
