# 通用几何计算与验证

## 建议的数据与计算方式

- 在当前姿态的世界坐标中求解。保留求值前后的拓扑对应；若修改器改变了拓扑，不假定索引一致。
- 从 Blender 导出只读求值几何，在独立数值环境中计算候选结果，再回写明确的目标对象。离线预览不要覆盖用户工作场景。
- 骨架未烘入时，应使用经验证的变形逆映射写回基础网格或形态键。不要将最终世界坐标简单逆乘对象矩阵后写入仍受骨架控制的基础网格，那会重复变形。
- 保存完整恢复点，并单独保存当前源坐标、拓扑、自由区域掩码、结构线约束及验证结果。
- 固定区直接复用原局部坐标可避免世界坐标往返的浮点变化；验证时设置与模型尺度相称的容差。

## 局部自定义法线修复的实现注意

- 先查询当前 Blender 版本的 API 与属性类型。在副本上验证行为；不要把一次版本中的内部属性名称或编码方式当作稳定通用接口。
- 本次案例中，细分后的 `custom_normal` 面角数据导致假褶皱。仅调用 `normals_split_custom_set` 传入零向量的试验未消除显示异常；移除并重新建立属性、在脚部使用自动法线后才消失。没有据此进一步确定是缓存还是具体编码处理导致第一次无效。
- 本次局部方案先保存所有面角的原始编码，重建法线属性，仅重置脚部，原样恢复其他面角数据；修改前后核对了未处理区编码、顶点和锐边均不变。这种编码恢复仅适用于法线修复期间拓扑及面角顺序未改变的情况；若顺序变化，必须先建立可靠对应。
- 不默认全物体移除自定义法线。保留备份，验证已验收区域的原着色，并在实际资产上复现前后效果。

## 接触与自交验证

- 顶点、边中点和面中心只是采样。长三角形、弯曲身体表面与薄层需要加密采样或对检测到的相交面自适应检查。
- 几何变化后重新三角化；同一个四边形的三角划分可能改变，不可复用旧三角面编号。跨轮保存问题面时可保存顶点集合与所属原始多边形。
- 自交检测先排除共享拓扑边/顶点的正常邻接，再区分同片折叠、层间穿透与原有装饰接触。原始交叠也不自动意味着正确，只是不应把它混同为新增问题。
- 不同三角划分、微小数值误差与共面接触会影响配对计数。报告明确检测范围与容差，不用计数代替空间位置和视觉判断。
