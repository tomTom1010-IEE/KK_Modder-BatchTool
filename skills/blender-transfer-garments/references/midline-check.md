# 对称模型中央布线稳定检查

中央布线是早期预警，不是自动拉直指令。源模型确认对称、该区域也应保持对称时，在迁移前、每轮几何修改后和最终交付前检查。固定区域仍可只读复查；发现旧缺陷时不得以“本轮没改”视作通过，也不擅自扩大修改范围。

## 判断原则

- 用干净源模型确定中央边链、左右成对顶点及有效对称平面，保存源到当前顶点对应。源中线随胸腹或裆底沿矢状面弯曲可以是正常轮廓；所谓平直主要指左右居中、正/背视投影不蛇形，不能把它强制拉成三维直线。
- 从正确的模型/骨架参考坐标检查。对象移动、旋转、父级缩放与非对称姿态不是网格损坏；使用对应静止姿态或可信的局部参考框架。不能假定世界 X=0，也不能重新拟合已歪曲中线来掩盖漂移。
- 故意不对称的衣服、斜襟、偏置装饰和非对称目标体型应分区排除或明确记录预期差异，不强制镜像。缺少可靠源对应或对称参考时标为不确定。
- 从源中线追踪当前中线，不从“当前仍靠近平面”的顶点重新选择，否则最需要检查的漂移顶点会被漏掉。跨拓扑变化需重建对应并核对边连接，不能依赖旧编号或相同顶点数。
- 检查离面对称偏移、左右折返、相邻边横向突跳、分叉连接、左右宽度失衡以及成对顶点越过中线。异常时扩大只读诊断到相邻面：检查挤团、边长压缩、层顺序、凸凹翻转、局部自交、法线和错误表面对应。
- 偏移阈值按资产单位、局部饰带宽度及源误差设置。不能仅用全模型尺寸给窄裆带设置过大的容差。稳定中线不证明周边几何完好；平面内的折叠、原有不对称和厚度问题仍需其他检查。

## 随技能提供的只读脚本

[check_garment_midline.py](../scripts/check_garment_midline.py) 使用标准 Python，无 Blender 或第三方依赖；读取几何 JSON，只写诊断报告，不修改模型、选择状态或法线。通用工具主文件位于项目 `garment-workflow/tools/check_garment_midline.py`，本技能打包同内容副本，安装后可以独立使用。

```text
python check_garment_midline.py input.json --output report.json
```

输入示例（坐标与容差使用同一单位）：

```json
{
  "source": {"vertices": [[0,0,0],[0,0.2,1],[-1,0,0],[1,0,0]], "edges": [[0,1]]},
  "target": {"vertices": [[0,0,0],[0,0.3,1.2],[-1.1,0,0],[1.1,0,0]], "edges": [[0,1]]},
  "source_plane": {"origin": [0,0,0], "normal": [1,0,0]},
  "target_plane": {"origin": [0,0,0], "normal": [1,0,0]},
  "center_ids": [0,1],
  "source_to_target": [0,1,2,3],
  "mirror_pairs": [[2,3]],
  "tolerance": 0.0005
}
```

- `center_ids`、`mirror_pairs` 均为**源**编号，只包含确认对称的区域；成对检查可省略。边链通过源 `edges` 中的连接确定。
- `source_to_target` 是经核对的一对一映射，长度等于源顶点数；缺失用 `null`，不能随意补最近点。两侧平面法向应指向对应的同一侧。
- 在 Blender 中从当前求值网格导出世界坐标或统一参考坐标，同时导出同一求值网格的边；映射必须对应这些求值顶点。编辑模式先同步数据，改变拓扑的修改器必须重新核对映射。无需调用任何修改顶点的操作。
- 报告包含偏移源/目标编号、带横向突跳的边、缺失对应和左右反射误差。`pass` 只表示提供的检查项通过；`warning` 表示需检查邻域；`inconclusive` 表示没有完整中线覆盖；`invalid_input` 表示参考或映射无效。退出码分别为 0、1、2、2。
- 当前脚本检测离面偏移、边上横向距离突变及显式提供的镜像点对；**不自动推断语义中线，不检测平面内折叠、全部拓扑分叉或自交，不直接判定损坏原因**。变更拓扑后的边链重建、非平面参考中线和实际可见性由工作流另行检查。

不要见到告警就把 X 坐标清零。先区分合法姿态/设计变化与损坏，再从源剖面或备份修复整个局部结构，最后重新检查贴合、凸凹、厚度、自交和法线。
