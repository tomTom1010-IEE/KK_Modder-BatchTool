# 衣物迁移素体：通用流程

迁移体型与姿态时保留原服装设计，按衣物用途决定松量。宽松衣物不能以全表面贴身为目标。处理紧身衣时，完成此通用流程的准备后，再读取同级 [贴身衣物专用技能](../blender-fit-close-garments/SKILL.md) 中的贴合策略；本技能负责共用流程和设计保留，专用技能不重复这些内容。

## 范围与资产约束

- 确认用户指定的衣物、素体及可修改范围；不硬编码过去任务的名称、骨架、坐标、顶点编号或路径。
- 不通过修改素体、隐藏身体面、删除装饰或填补设计开口掩盖迁移问题，除非用户明确要求。
- 默认保留骨架、形态键、拓扑、UV 和材质。用户允许烘入或移除时可简化，但烘入当前姿态后不能重复叠加原骨架变形。
- 遵守用户对修改器和算法的限制。有厚度或装饰时不能将各层独立压到同一表面；静态迁移也不等于权重或动画验证完成。

## 开始前：读取、备份、建立基线

1. 确认实际可用的 Blender MCP 工具。优先用场景和对象查询工具；需要读取几何、运行专门算法时再执行 Blender Python。
2. 检查当前模式、活动对象、选择、可见性、集合、共享网格、父级、修改器目标、形态键值、材质和 UV。读取坐标前处理编辑模式数据同步。
3. **任何顶点修改之前保存可恢复的备份。** 用户要求备份上一步时，保存此刻完整场景副本，不能仅指向更早的备份。确认保存成功再动手。不要覆盖源文件。
4. 导出衣服与素体在当前姿态下的最终求值网格，统一到世界坐标计算。对象面板显示缩放为 1，并不代表父级变换没有缩放。
5. 同时保存未损坏的源衣服及顶点对应关系。记录拓扑、锐边、UV、材质分配、原始局部坐标与求值坐标的区别。只存坐标 JSON 不能代替完整网格备份。
6. 获取正、背、侧视图，并按任务查看裆底、腿内侧、腰部和足底近景。截图黑屏不能算检查通过；可在独立进程中用求值网格生成检查图，不改变用户场景的灯光、相机和材质。

需要离线计算、回写求值网格或编写相交检测时，读取 [计算与验证细节](references/geometry-workflow.md)。不要假定 MCP 多次代码执行共享变量；按实际工具契约处理返回值及状态。

## 结构分解与附属件

通过连通分量、材质、锐边、边界、法线和空间关系识别：

- 衣料主体；
- 内外厚度层、翻边、接缝和包边；
- 独立饰条、徽记、硬质或半硬质部件；
- 镂空、脚趾和脚跟开口等设计边界。

连通分量不等同于设计部件：同一分量可能包含厚度层，不同分量也可能属于同一条装饰。

给厚度层和附属件建立邻近衣料的局部对应，使它们跟随衣料的平移与旋转，而不是独立贴到素体。可用局部坐标框架、重心坐标附着、空间耦合或平滑变形场。验证厚度是否被保留，不能仅凭“使用了平滑算法”就宣称保厚度。

## 识别并保留原服装设计

迁移前建立设计特征清单和源网格对应，区分原有设计、迁移后新增畸变和素体异常。以干净源模型为依据，不能仅从已经平滑或变形的结果反推设计。

- 同时查看实体、线框、锐边/折痕标记、面法线和材质分区。锐边标记是线索，不是完整设计清单；无标记的几何褶皱也需保留。
- 用户局部选择或截图只提供示例，不表示其他结构可以忽略。沿布线延伸，并检查相邻区域、侧后方及对侧的同类结构；不要自动强制对称，源模型可能有不对称设计。
- 记录特征的端点、交点、边链、相邻支撑面、横截面和裁片内的相对位置。顶点数相同不足以证明索引对应；拓扑改变后重新建立对应。

### 刻意笔直的锐边和分区线

- 对照源模型识别明显设计为直线的边链，保持其直线语义及与裁片的关系。不要把所有锐边一律拉直，也不要取消锐边标记掩盖弯曲。
- 区分三维共线、指定视图投影为直线和沿曲面平顺。按原设计与用户要求约束；投影拉直时仍可保留随身体变化的深度。
- V 形结构分别保持两臂及交点；保留与腿口等边界的连接。线约束要贯穿贴合、接触修正和平滑，不应在后续步骤被弯回去。

### 有意制作的褶皱布线

- 识别成组窄面带、脊线/谷线、逐渐收尖的端点、相邻支撑边及连续走向。例如用户示意的腹部横向褶皱，选中部分和未选中的同类褶皱都属于检查范围。
- 保留褶皱数量、走向、相对位置、脊谷顺序、宽度、起伏及端部收束。随体型作合理适配，不要求世界坐标尺寸完全不变，也不能只保留边数却把立体起伏抹平。
- 用源模型判断褶皱是否本来存在。只消除迁移产生的挤团、折叠和波纹；不要把“腰部平顺”解释为删除原有褶皱设计。褶皱的弯曲也不能因附近有直锐边而被整体拉直。
- 对基底曲面与设计细节分开处理：先迁移低频轮廓，再用局部坐标框架携带源褶皱的脊谷与支撑面，或在求解中显式约束它们。局部框架随衣服旋转，不能机械叠加旧世界坐标位移。
- 平滑、截面重建和碰撞修正需保护这些特征及过渡带。若贴合约束冲突，优先通过邻域整体位移或合理衣料余量解决；不要独立吸附脊谷，把褶皱压到同一身体表面。
- 不确定的特征先保留并核对源模型；在缺少源模型时标明判断依据和不确定性，不以“平滑更好看”为由删除。

### 保持整齐的布线

- 将源模型中整齐、渐变均匀的顶点分布作为迁移约束。检查纵向边线是否连续顺畅、环线是否发生局部折弯、相邻行列间距是否突变；表面没有穿模不代表布线质量合格。
- “整齐”以源模型和目标曲面为依据，不强制所有边等长或所有环线水平。保留关节加密、褶皱支撑线、锐边、收尖及设计上不均匀的布线，不改变拓扑来掩盖顶点排列问题。
- 在源对应可靠时，可对源到当前衣服的变形场作局部平滑，恢复较规则的顶点分布，再沿已贴合衣服的可信曲面调整位置。优先整理普通衣料区域；复杂装饰、膝踝结构、开口边缘和已认可区域保持固定，并设置连续过渡带。
- 不直接用无约束平滑作为最终结果：它可能收缩进素体。也不把所有部位独立投射到同一表面；厚度层与附属件需保持相对关系，投射到错误层或遇到开口时应回退该局部方案。
- 整理后检查实际面与身体相交、修复区自交、设计线和边界间隙。必要时以邻域平顺外移补足间隙，避免逐点推挤重新打乱布线。允许符合衣物用途的少量余量增加，但应比较并说明前后间隙，不得以明显变松换取整齐。
- 用一致视角的正、侧、背面线框对照源模型及修改前结果，确认改善不仅发生在单个视角。局部成功不能视为全身布线均已整理。

## 稳定作业检查：对称模型的中央布线

对源模型确认对称且目标应保持对称的区域，在迁移前建立中央边链基线，并在每轮几何修改后与最终交付前复查。中央布线偏移或蛇形折弯是局部损坏的预警；即使相交计数正常，也应检查邻域挤压、扭转、厚度层、凸凹剖面和法线，不能直接判定通过。

- 保持中线左右居中及原设计要求的投影平直；沿胸腹、裆底的正常前后起伏不应被拉成三维直线。使用正确的对称平面和姿态，排除原有不对称设计与目标体型的合理不对称。
- 根据源对应追踪中线，不能从当前靠近平面的顶点重新挑选，否则会漏掉已漂移顶点。同步检查左右邻边宽度、跨中线和局部突跳；拓扑变更后核对映射与边链。
- “已认可区域不改动”不等于“免于只读检查”。已有缺陷不能仅因本轮未新增而算合格；发现异常先诊断，不能自动归零坐标或镜像整个模型。

检查时读取 [中央布线检查方法与只读脚本](references/midline-check.md)。脚本报告是预警，不能代替剖面、折叠、自交和实际着色验收。

## 局部迭代

用户已认可区域保持固定，只开放问题区及必要过渡带。坏网格存在有效源对应时，从干净源区域恢复再迁移；不能在已挤坏顶点上无限推点。固定区直接保留原局部坐标，避免不必要的坐标往返误差。

## 每次几何修改后的法线检查

**任何顶点位置或拓扑修改后，都要检查法线和实际着色。** 这是通用检查要求；不代表每次都清除或重建自定义法线。

- 区分几何面法线、网格自定义分裂法线（面角法线）和材质的法线贴图。修复网格着色不等于修改法线贴图，不默认改纹理或材质。
- 顶点移动、细分和坐标变换后，原自定义法线可能不再适配；属性仍存在或完成插值，不代表显示正确。检查是否出现源模型没有的密集明暗条纹、假褶皱或接缝。
- 在实际网格副本上做同视角、同光照对照：保留几何和锐边，仅将可疑区域改用当前几何计算的法线。若异常随法线重建消失，可定位为着色问题；若仍存在，则继续检查实际折叠、面朝向、锐边/平滑设置、重叠面或材质，不能仅凭外观认定原因。
- 确认自定义法线异常后，优先局部重建，保留其他区域尤其已验收部位的法线。保护设计硬边和平滑分区，不通过取消锐边或移动顶点来掩盖纯法线问题。原有专门制作的法线效果也需对照保留。
- 验证修复确实生效并更新显示。若所用版本的重置方式没有清除异常，在副本中核对法线属性和缓存后再处理；不要盲目全物体清空。实施细节见 [计算与验证细节](references/geometry-workflow.md)。
- 最终用实际对象或保留完整法线、平滑设置和材质的场景副本检查。仅从顶点和面重新建网格会丢失自定义法线，可能把实际资产的错误隐藏起来。
- 纯法线修复应验证顶点、拓扑、锐边及未修复区法线未变；这样原有贴合与碰撞关系才保持不变。交付时明确说明修改的是网格法线还是几何或贴图。

## 验收与回退

完成前同时满足以下检查，而非只挑选通过的一项：

1. **范围**：素体没有变化；固定区位移为零或可解释的浮点误差；未误改其他对象。
2. **贴合**：按衣物用途检查松量和可见边缘间隙；涉及鞋、裤装时额外检查足底、腿内侧和裆底；保留设计开口。
3. **几何**：与素体相交、衣料自身折叠、跨层互穿分别检查。区分同片自交与原有装饰交叠，列出残留问题。
4. **质量**：查看纵线连续性、环线走向与行列间距的渐变，并对照源模型区分设计加密与意外挤团；对称区域必须复查中央布线居中与投影平直，异常时检查邻域扭曲；同时检查局部边长压缩、面面积、面翻转、长细面、顶点聚集、厚度和左右关系。低相交计数不能替代这些检查。
5. **设计**：逐项对照源特征清单检查直锐边、原有褶皱的脊谷及收尖、分区线、厚度层和饰条。检查未选中的同类结构；不能仅凭锐边属性仍在或拓扑未变就判定设计已保留。
6. **外观**：检查正、背、侧面和局部近景，必要时加线框；使用同一相机和光照作前后对比，并检查修改后的自定义法线。最终预览保留实际资产的法线与着色数据。辅助叠加线不等于实际网格已正确，需核对真实顶点。
7. **资产**：UV、材质和需要保留的权重/形态键等属性仍有效；若已烘入，说明这一变化。

若数值指标改善但出现可见折叠、设计破坏或新褶皱，拒绝该候选结果，回到最近合格检查点改变方法。若连续两轮仅在相同问题上反复增减间隙，不继续堆叠参数：重新检查对应关系、约束和参考网格。无法在当前限制下同时满足要求时，保留最后合格版本并说明具体未解决项，不把试验结果称为完成。

保存新结果副本，保留用户源文件及备份。交付简短说明：修改对象与区域、是否烘入变形、关键检查结果、限制、备份与结果路径。用户未要求时，不把静态贴合扩展成权重传递、烘焙或动画制作。
