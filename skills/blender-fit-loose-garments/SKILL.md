# 非贴身衣物适配素体

先读取 [衣物迁移素体通用技能](../blender-transfer-garments/SKILL.md)，执行其 MCP 操作、备份、坐标处理、设计保护和法线验收流程。这里仅补充非贴身衣物的决策。没有动骨的宽松衣物也适用，跳过骨链接入部分。

## 保留原款松量与穿着关系

目标是把原款的穿着效果迁移到新体型，而非把衣服处处贴紧，也不是单纯消除相交。

- 对照原衣物与原素体、原内搭的组合，以及目标素体与已适配内搭的组合。记录肩点、领根、胸口、腋下、袖长、下摆高度和腰部比例；不要仅按人物总高或包围盒等比放大。
- 分清承托或贴近身体的区域（如肩部、领根）、有意留空的衣料、翻领/帽兜/垂坠部件和收口。余量按原设计分区，不能把“宽松”扩散成悬空的肩胸和张开的巨大领口。
- 比较相近视角下的领口开口宽度、肩上空隙、胸前离体距离、袖子体积和下摆轮廓。零穿模但明显偏离原款，仍需修正。
- 对异常素体突起保留原衣服的平顺轮廓，不复制非设计细节；覆盖约束仍然有效。不要擅改身体或内搭来迎合外衣。
- 建立穿着组合：素体、内搭及同时穿着的其他衣物都是障碍物；闭合款/敞开款等互斥版本分别检查，不要求它们彼此避让。不要仅凭名字推断互斥关系。

## 区域适配与接触修正

1. 先对齐人体区域和服装比例。用肩、肘、腕等解剖位置对应处理袖子；骨轴朝向不同的骨架不能直接用整套静置矩阵映射衣物。
2. 原内搭与已适配内搭有可靠顶点对应时，可用它们建立局部变形场，让外衣保留相对于内搭的轮廓、松量与层次。没有可靠对应时使用解剖标志或受控变形笼，不能编造顶点对应。
3. 肩胸或领口过空时，从源设计恢复该区的对应，再收回余量；不是在已经撑大的结果上继续叠加全局缩放。袖口、下摆等已认可区域固定，只留必要过渡带。
4. 只对收回后实际接触的局部补足间隙。修正连续传播到相邻衣料，厚度层、翻边和附属件共同跟随。避免将各层分别吸附到身体。
5. 保留原有褶皱、直锐边与整齐布线。长袖带、拉链、饰条等必要时使用独立的局部仿射/刚性跟随，防止邻域变形把原本直的设计折弯；原本弯曲的部件不强制拉直。
6. 每轮都比较视觉余量与真实面相交。不要为了清零交叉而把整个肩胸向上、向外撑开；也不要只统计顶点距离而漏掉低模大面的穿插。

编写求解器或遇到反复穿模、厚度层折叠时，读取 [方法与已验证的教训](references/methods-and-lessons.md)。其中算法是可选实现，不是固定参数配方。

## 动骨与辅助骨识别

非贴身衣物可能依赖动骨，不能沿用测试紧身衣时清理骨架、烘入姿态、删除形态键的做法。

- 检查源骨架类型与可用的人体骨语义映射，再结合服装实际使用的非零顶点组、层级和约束识别所需骨链。来源可能是 VRC、MMD 或自定义骨架，禁止硬编码为某一套骨名。
- “非 Humanoid 骨”是本次 VRC 案例的候选筛选线索，不是物理骨的充分定义。其中还可能包含乳房/手臂辅助变形骨、控制骨、IK 骨和其他衣物骨，需分别判断依赖与用途。
- 保留需要的完整链路：受权重影响的骨、必要的未加权根骨/中间骨/末端骨，以及约束或驱动依赖。不要仅复制有顶点组的骨，也不要把其他衣物的所有非人体骨整包迁入。
- 检查物理元数据、约束、驱动、刚体及关节是否实际存在。骨名或骨链存在不等于物理系统已配置；未随模型导入的运行时数据不能声称已经迁移。

## 网格和骨链接入目标骨架

- 从完整场景备份开始，先在副本验证。网格与相关骨骼使用一致的空间变形或可验证的局部对应，骨头、骨尾和横向参考轴一起适配；只移动骨头会破坏长度或方向。
- 将链根接到目标骨架语义对应的胸、肩、上臂、前臂等父骨。考虑目标父骨的实际姿态与静置状态，保持接入时的预期世界位置；不要为迁衣随意改变目标原有静置骨骼或姿态。
- 保留链内父子关系、roll、变形标志和相关继承设置；连接关系按适配后的几何检查，不能强行吸到不匹配的父骨尾端。处理重名时先建立显式映射，并维护所有引用，不能依赖 Blender 自动加后缀。
- 网格父级和骨架修改器一起更新，核对父级逆矩阵与求值结果，防止重复变换。约束、驱动或物理对象若引用旧骨架，须按实际范围重定向或明确留下待办。
- 迁走专用骨之前，检查源骨架剩余网格和约束/驱动等使用者。共享骨可复制到目标并在源骨架保留；不能因迁走夹克而破坏仍使用它们的配件。
- 同一衣物的互斥版本若共用一套骨链，使用一致的骨骼适配；必须独立调整时明确分链并维护引用，避免后一版本覆盖前一版本的静置形态。

### 权重范围与接入验证

- 网格适配、骨链接入、权重迁移和运行时物理配置是不同交付项。用户只要求前两项时，保留现有顶点组及权重，不擅自重命名人体组、传权重、自动绑定或归一化。
- 原有组名若与接入的动骨一致，其权重可继续生效；人体组未映射到目标骨架时，明确说明完整人体动作跟随尚未完成，不能为了演示“接入成功”暗中修改权重。
- 骨骼位置变化后检查静置求值网格，避免外观跳动。对代表性的动骨做小角度旋转，验证相关顶点和子链响应，然后恢复原姿态；同时检查链根父级关系。此测试不能替代完整动作、物理模拟或碰撞验收。
- 形态键随迁移一致适配并检查相对形态；需要验证哪些键及其组合取决于用户范围。保留键名不代表所有极值形态都已验收。

## 专用验收与交付

执行通用技能的完整检查，并增加：

- **原款比例**：肩胸贴近程度、领口落点和开口尺度合理；保留宽松轮廓，不能以过度膨胀换取不穿模。
- **叠穿关系**：每个穿着组合分别与素体及内层衣物检查；不互查互斥版本。顶点、边和面内部采样用于求解，真实三角面相交用于复核。
- **骨架接入**：完整链路、父级语义和引用正确，目标原有骨骼未被误改；源骨架剩余使用者未受损。
- **资产与局部范围**：核对权重、拓扑、UV、材质、锐边、形态键及固定区位置；按通用流程检查修改区自定义法线和未修改区法线。
- **自交基线**：区分源模型已有装饰交叠、跨部件新增交叠和同片衣料折叠。交叠发生在不同连通分量并不自动合理；实际定位并说明残留，不把身体交叉为零说成全资产无问题。

保存新结果与操作前备份。交付说明当前显示的版本、骨链接入情况、是否处理权重和运行时物理，以及残留交叠/未验证姿态。后续用户只反馈某区域时，保持已验收部位固定。
