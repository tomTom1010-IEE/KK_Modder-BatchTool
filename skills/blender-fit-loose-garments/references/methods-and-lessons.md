# 非贴身迁移：实现选择与案例边界

本记录来自闭合/敞开两款夹克的网格适配和骨链接入测试。第二轮收回肩胸、降低并收拢领口后获用户验收。未迁移人体权重，也未完成引擎内物理模拟验收；不能把本例推广为完整动画制作流程。

## 用已适配内搭建立局部对应

若原内搭与目标内搭有可靠的顶点映射，可通过局部加权仿射拟合，把原外衣在内搭附近的相对形态迁移过去：

1. 将源对应点和目标对应点转换到一致的世界坐标。检查映射覆盖和语义，细分后的新增顶点不自动具有源索引。
2. 对待迁点附近的源对应点赋距离权重，求源/目标加权中心与协方差，拟合局部仿射变换。
3. 薄表面法向方向可能缺少约束；用合理的整体变换作正则先验，避免退化矩阵造成法向过度伸缩或翻面。邻域不能跨左右、内外或错误解剖区域。
4. 将局部结果与已认可的区域连续混合，固定区直接使用原坐标。检查局部变换的方向、面面积、厚度和边线，不因正则化就假定结果可靠。
5. 对形态键可同步变换各键，或在适合的小幅修正中给各键叠加一致的局部位移；后者只保留原相对偏移，并不能证明极值键仍适合新体型。

本例用原紧身内搭与已适配内搭建立局部对应，比依靠全局比例和宽泛的最近点残差更能恢复肩胸关系。没有对应数据时不能照搬此实现，应换成解剖标志或变形笼。

## 从叠穿外表面求接触余量

本例成功的修正流程是先恢复原款局部形态，再仅向外补足接触余量，而非全局增厚、抬肩：

- 障碍集合包含目标素体和当前穿着的内搭；每个互斥外衣版本分别求解。
- 同时在顶点、边中点和面内部采样。素体最近表面的可信外法线可提供局部搜索方向；从外侧沿反方向射线查询障碍集合，寻找该局部最外层遮挡面，再计算缺少的间隙。
- 射线起点必须在相关局部之外，范围要覆盖该区域但不能穿过整个身体寻找错误层。骨骼错位、异常突出、开口、凹腋下、双层衣料及不一致的面朝向都需要检查；射线漏检不代表安全。
- 对所需位移作连续的邻域传播，限制单次幅度，使邻近厚度层共同移动。完成后用真实面相交复核，因为采样和射线不能证明所有面都无穿插。
- 尺度、邻域大小、正则、射线长度、迭代幅度和间隙都随资产选择。本例数值不能变成通用固定常数。

不要仅把最近面的法线按“朝远离躯干中轴”的规则翻转：领口、帽兜和厚度内壁并不满足简单径向假设，本例早期因此产生错误推力和折叠。

## 骨骼随形与保持原权重

可用同一变形场迁移骨头、骨尾及横向轴上的参考点，再从迁移后的纵轴和横向参考恢复 roll。若在已接入版本上局部修形，可用修改前后衣料的连续位移场更新相关骨链，固定无关链和目标人体骨。

骨架轴向、继承缩放、非零姿态和对象父级变换都可能使“静置看起来没变”不成立。应比较接入前后的求值顶点，而不只比较网格 datablock 坐标。静置误差按模型尺度分析，不能不断放宽阈值掩盖系统性的错误。

分类可参考资产来源的语义表。本例参考了用户的 [KK_Modder-BatchTool](https://github.com/tomTom1010-IEE/KK_Modder-BatchTool) 中 VRC 人体/辅助/衣物骨规则；只在处理类似来源时查阅当前实现，不能把其中名称当成 MMD 或自定义骨架的标准。

本例保留了夹克实际依赖的完整非人体链，其中包括袖带、下摆和辅助变形骨。仍被其他配件使用的共享骨在源骨架中保留。复制数量和具体骨名是案例结果，不是筛选规则。

## 失败方案及对应修正

| 观察 | 原因或风险 | 修正方向 |
|---|---|---|
| 无身体穿模，但肩胸空、领口过大 | 用整片抬高/向外扩张消除局部交叉，改变原设计松量 | 恢复源衣物与内搭的局部对应，只给接触点补小间隙 |
| 交叉减少，但领边、厚度层折叠增多 | 错误内外表面判断及不连续的局部推点 | 拒绝该候选，核查外表面与区域对应，使用连续的耦合修正 |
| 原本直的袖带变弯 | 袖口局部变形场不应直接作用到整条直饰件 | 独立仿射跟随或明确的直线约束，同时更新对应骨链 |
| 胸口产生源模型没有的明暗斑块 | 迁移后的自定义角法线或其变换估计不稳定 | 按通用技能做同几何法线对照，确认后局部重建，保留其他区与锐边 |
| 检测结果只报告身体交叉为零 | 忽略内搭、饰件交叠、内部折叠或视觉松量 | 分项验收；追踪源基线与新增问题，明确未覆盖的姿态和形态键 |

验收通过说明这一具体静态结果符合用户要求，不代表原模型装饰交叠全部消除，也不代表后续任意动作或形态键都不会穿模。
